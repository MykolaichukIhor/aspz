---

## Завдання: Локальний чат між двома користувачами через FIFO

### Опис

Реалізовано консольний локальний чат для двох користувачів з використанням механізму FIFO (named pipes) у Linux. Програма дозволяє двом окремим процесам або користувачам обмінюватися повідомленнями в режимі реального часу.

---

## Пояснення роботи програми

Програма використовує два FIFO-канали:

- `/tmp/chat_fifo1`
- `/tmp/chat_fifo2`

Кожен користувач одночасно:
- читає повідомлення з одного FIFO;
- записує повідомлення в інший FIFO.

Для паралельної роботи використовується багатопотоковість (`pthread`):
- головний потік відповідає за введення та відправку повідомлень;
- окремий потік (`reader_thread`) постійно очікує та читає вхідні повідомлення.

Для уникнення блокування FIFO відкриваються у режимі `O_RDWR`.

При запуску користувач передає:
- номер користувача (`1` або `2`);
- власне ім’я.

Після підключення програма:
- показує повідомлення про підключення співрозмовника;
- відображає час кожного повідомлення;
- підтримує команду `/quit` для виходу;
- підтримує завершення через `Ctrl+C`.

Для завершення роботи:
- закриваються файлові дескриптори;
- потік читання завершується;
- FIFO-файли видаляються.

---

## Компіляція програми

```bash
gcc local_chat.c -o local_chat -pthread
```

---

## Запуск програми

### Перший користувач

```bash
./local_chat 1 Alex
```

### Другий користувач

```bash
./local_chat 2 John
```

## Висновок

У ході роботи було реалізовано механізм міжпроцесної взаємодії (IPC) за допомогою FIFO-каналів. Програма демонструє роботу з:
- named pipes;
- потоками (`pthread`);
- сигналами (`SIGINT`, `SIGTERM`);
- синхронним обміном повідомленнями між процесами.

Реалізований чат дозволяє двом користувачам обмінюватися повідомленнями в реальному часі через консоль Linux.
